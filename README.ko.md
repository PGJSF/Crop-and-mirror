# Crop & Mirror

[English](README.md) | [한국어](README.ko.md)

Godot 에디터에서 이미지의 영역을 선택해 PNG로 잘라내거나, 수평·수직으로 대칭 복제하여 대화창 같은 UI 프레임 이미지를 만드는 애드온입니다. 대칭을 끄면 단순 크롭 도구로도 사용할 수 있습니다. 프로젝트 설정에는 **Crop & Mirror**라는 이름으로 표시됩니다.

대상 환경: **Godot 4.7**. Godot 4.7.2에서 스크립트 검사와 언어 전환을 검증했습니다.

## 설치 및 실행

1. `addons/crop_and_mirror` 폴더를 프로젝트의 `res://addons/` 아래에 넣습니다.
2. 프로젝트 설정의 **Plugins** 탭에서 **Crop & Mirror**를 활성화합니다.
3. 에디터 하단의 **Crop & Mirror / 크롭 & 미러** 패널을 엽니다.

## 빠른 사용법

1. **Load Image / 이미지 불러오기**로 원본 이미지를 선택합니다. FileSystem 도크에서 이미지 파일을 캔버스나 미리보기 영역으로 드래그해도 됩니다.
2. 왼쪽 캔버스에서 사용할 모서리 영역을 드래그하여 선택합니다. 이미지를 불러오면 기본적으로 좌상단의 1/4 영역이 선택됩니다.
3. **Source Corner / 원본 모서리**에서 선택 영역이 완성 이미지의 어느 모서리에 해당하는지 지정합니다.
4. **Mirror H / 수평 대칭**, **Mirror V / 수직 대칭**을 설정하고 **Live Preview / 미리보기**에서 결과를 확인합니다.
5. **Output Path / 출력 경로**를 확인한 후 **Export Dialog Box Image / 대화창 이미지 생성**을 누릅니다.

예를 들어, 대화창의 좌상단 모서리 이미지가 있다면 해당 영역을 선택하고 **Top-Left / 좌상단** 및 두 대칭 옵션을 사용합니다.

## 영역 및 대칭 설정

| 항목 | 설명 |
| --- | --- |
| X, Y | 원본 이미지에서 선택 영역의 좌상단 좌표. 단위는 픽셀입니다. |
| Width / 너비, Height / 높이 | 선택 영역의 크기. 숫자를 입력하여 정밀하게 조절할 수 있습니다. |
| Source Corner / 원본 모서리 | 좌상단, 우상단, 좌하단, 우하단 중 선택합니다. 영역을 좌상단 기준으로 정규화한 뒤 대칭 복제합니다. |
| Mirror H / 수평 대칭 | 선택 영역을 좌우로 대칭 복제합니다. |
| Mirror V / 수직 대칭 | 선택 영역을 상하로 대칭 복제합니다. |
| Horizontal Overlap / 좌우 겹침 | 좌우 대칭 영역이 중앙에서 겹치는 픽셀 수입니다. 설정 범위는 0~32이며, 수평 대칭을 끄면 입력이 비활성화됩니다. |
| Vertical Overlap / 상하 겹침 | 상하 대칭 영역이 중앙에서 겹치는 픽셀 수입니다. 설정 범위는 0~32이며, 수직 대칭을 끄면 입력이 비활성화됩니다. |
| Output Size / 출력 크기 | 현재 설정으로 생성되는 이미지의 최종 크기입니다. |

선택 영역의 크기가 `W × H`이고 두 겹침 값이 모두 `0`이면, 두 대칭 옵션을 켰을 때 출력 크기는 `2W × 2H`입니다. 예를 들어 `64 × 32` 영역은 `128 × 64` 이미지가 됩니다.

두 대칭 옵션을 켜면 출력 크기는 `(2W - 좌우 겹침) × (2H - 상하 겹침)`입니다. `64 × 32` 영역에서 좌우 겹침을 `2`, 상하 겹침을 `0`으로 설정하면 `126 × 64` 이미지가 됩니다.

실제 겹침은 해당 축의 선택 영역 크기보다 최소 1픽셀 작게 제한됩니다. 대칭을 끈 축에서는 겹침을 적용하지 않으며, 입력값은 유지되어 대칭을 다시 켜면 재사용됩니다. 겹친 부분은 나중에 복제한 영역의 픽셀로 덮어씁니다.

## 언어 변경

상단 툴바 오른쪽 드롭다운에서 **English** 또는 **한국어**를 선택합니다.

- 기본 언어는 English입니다.
- 버튼, 설정 항목, 안내문, 상태 메시지 및 하단 패널 제목이 즉시 변경됩니다.
- 이미 표시된 성공·오류 메시지도 선택한 언어로 갱신됩니다.
- 이미지, 선택 영역, 확대율, 대칭 설정과 출력 경로는 유지됩니다.
- 선택한 언어는 프로젝트별 에디터 메타데이터에 저장되어 에디터를 다시 열어도 유지됩니다.
- 이 설정은 애드온에만 적용됩니다. Godot 에디터 전체의 언어는 변경하지 않습니다.

## 파일 불러오기 및 내보내기

- 파일 선택창과 FileSystem 도크 드래그 모두 PNG, WebP, JPG, JPEG, BMP, SVG를 지원합니다.
- 출력 형식은 PNG입니다. 출력 경로에 `.png` 확장자가 없으면 자동으로 추가합니다.
- 기본 출력 경로는 원본 이미지와 같은 폴더의 `<원본 파일명>_full.png`입니다. 예: `res://UI/dialog_corner.png` → `res://UI/dialog_corner_full.png`.
- 출력 폴더가 없으면 생성합니다. 저장한 이미지는 에디터에서 스캔 또는 재임포트합니다.
- 원본과 동일한 출력 경로는 차단합니다. 다른 경로에 이미 존재하는 출력 파일은 덮어씁니다.

## 문제 해결

| 상태 | 확인할 사항 |
| --- | --- |
| 패널이 보이지 않음 | Plugins 탭에서 Crop & Mirror가 활성화되어 있는지 확인합니다. |
| 이미지를 불러올 수 없음 | 파일 경로, 확장자와 이미지 파일의 유효성을 확인합니다. |
| 선택된 이미지가 없음 | 먼저 원본 이미지를 불러옵니다. |
| 선택 영역이 비어 있음 | 캔버스에서 영역을 선택하고 너비·높이를 확인합니다. |
| 출력 경로가 비어 있음 | `res://UI/dialog_full.png`처럼 출력 파일 경로를 입력합니다. |
| 출력 경로가 원본과 같음 | 원본과 다른 파일명을 지정합니다. |
| 저장 실패 | 상태 메시지의 오류 내용과 출력 폴더의 쓰기 권한을 확인합니다. |
